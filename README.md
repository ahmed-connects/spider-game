Keyboard & Mouse Controls
Aim & Shoot Web: Left-Click anywhere near an anchor point above you to fire and latch a web.

Release Web: Right-Click (or let go of Left-Click) to detach and go flying.

Pump Swing Power: W / S (or Up / Down arrow keys) while swinging to reel in or pump momentum.

Cut Web: Spacebar (consumes limited fluid to instantly snap your web for precision drops)
